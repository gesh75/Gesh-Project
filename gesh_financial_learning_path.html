01 Orientation & the two services Core

Understand what GESH is and how the pieces fit before touching code.

Learn

02 Live portfolio data Core

Know where the numbers come from — and which cash figure is safe to size against.

Learn

  • Holdings, equity, and watchlist quotes are ingested via robin_stocks (MCP-first, with a robin_stocks fallback).
  • Deployable cash = portfolio_cash (settled, unleveraged). NEVER size against buying_power (leveraged margin on Gold) or cash (negative margin figure).
  • Snapshots carry a source tag and an age — a stale/offline snapshot is shown as "Cached", not "Live".

04 Risk math: Monte Carlo & Kelly Advanced

Quantify "how bad could it get" and "how big should this position be".

Learn

  • Monte Carlo: 1000 GBM simulations → median outcome, P5–P95 band, and 95% VaR in real dollars.
  • Kelly criterion: optimal position size from edge + odds → ADD / HOLD / TRIM with exact share deltas.
  • Reconciliation rules: when Kelly (sizing) and the AI (valuation) conflict, Kelly wins for size.
Try: POST /api/monte-carlo and POST /api/kelly; watch VaR fall and diversification rise as you spread a book across more names.

05 The 12-node consensus engine New

How GESH turns many independent signals into one verdict + confidence.

Learn

  • Each node votes BULLISH / NEUTRAL / BEARISH / ABSTAIN. A regime-conditional weighted tally → verdict + confidence (= active nodes / total).
  • The 12th node is LT_Macro — a long-term (1–3y) market-wide bias from VIX / Fear&Greed / margin debt.
  • Weighted directional nodes: Rel.Strength, Trend, Volume, Momentum, Fundamentals, Macro, ECG, Analyst, LT_Macro, News. Kelly (sizing) and FFT_Cycle (informational) are surfaced but out of the vote.

06 AI analysis & multi-LLM routing Advanced

How structured prompts become scored, grounded research — without hallucinated prices.

Learn

  • Claude is called with a forced tool schema so it must return structured JSON (scores, fair value, risks, verdict) — never free text.
  • Prices are grounded: the real latest quote is passed in so the model can't invent a price. Fair-value % is recomputed deterministically in the UI so it can't flip sign.
  • Model routing: Claude Sonnet (deep) / Haiku (batch), Gemini (contrarian second opinion), Ollama (offline fallback).

08 The customer surface (Analyze) New

The self-serve product: research any ticker + analyze your own book — fully isolated per user.

Learn

  • Any-ticker research cards: company-name→ticker search, 12-node consensus, momentum (RSI/MACD/Volume), trade setup (support/resistance → entry/stop/target/RR), earnings beat/miss, regime, cycle, fundamentals, analyst, news.
  • AI research card: one price-grounded Claude call per symbol / 15 min; degrades honestly to "temporarily unavailable" on an empty response.

  • Quotas & tiers: rolling-24h caps on live LLM calls, scaled by tier (observer 1× / trader 2× / desk 5×). Comp a tester with python3 auth_users.py tier <email> desk.

09 Execution tier: intent → gate → paper fill Advanced

How a verdict safely becomes a (simulated) order, with every decision audited.

Learn

  • A verdict becomes a typed TradeIntent → the 8-gate risk gate (kill-switch → market hours → confidence → position cap → order rate → cash floor → daily loss → data freshness).
  • Every gate verdict (approve/reject) is persisted to risk_decisions; every simulated fill to orders with an idempotency key.
  • PAPER_MODE=true is the default and must stay so until the autonomy gate is met.
