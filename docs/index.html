⬡ Overview

What is GESH Financial?

GESH Financial is a single-node Python platform that turns a live Robinhood portfolio into AI-driven trading intelligence. A FastAPI server on port 9000 ingests holdings via robin_stocks, runs a stack of quantitative engines and an 11-node consensus voting engine, then routes structured prompts to Claude and Gemini for deep analysis and contrarian second opinions.

Every signal is funneled through a typed TradeIntent contract and an 8-gate risk gate before a paper-mode execution layer simulates orders — with the whole signal → gate → execute chain audited to SQLite and scheduled by an APScheduler autopilot. Since June 2026, a deterministic daily analysis chain (launchd, 10:30 ET weekdays, ~4–6 min) runs the entire pipeline unattended — and a commercial surface (/track-record proof page, /watch cockpit, /invest radar, /report) exposes the results.

What started as a personal tool now also runs as an auth-walled customer product (public at pay.geshfinance.com): per-user accounts with isolated data, Lemon Squeezy subscriptions ($49 / $149 / $399) with rolling-24h usage quotas, a customer My Book surface, and legal scaffolding — /privacy, /terms and /disclaimer (DRAFT pending counsel) plus self-serve data rights (in-app export and account deletion). It ships as a monitored paid beta — educational framing, a signup-pause switch (GESH_SIGNUPS_PAUSED), 1 paying subscriber — with broad launch gated on attorney review of the publisher-vs-adviser classification.

Key Features

Ten product layers, each independently auditable, from raw signal nodes to gated execution, the daily chain that runs them all, and the commercial shell around them.

🗳️

11-Node Consensus Engine

Eleven intentionally uncorrelated signal nodes (momentum, trend, relative strength, fundamentals, analyst, live Reddit sentiment, Kelly, ECG, volume, FFT cycle, FRED macro) each vote BULLISH/NEUTRAL/BEARISH/ABSTAIN; the normalized score thresholds into STRONG BUY/SELL (≥0.55) or BUY/SELL (≥0.25).

🛡️

8-Gate Risk Gate

Every TradeIntent passes through ordered gates — kill-switch, market hours, confidence floor, position cap, order rate, cash floor, daily loss, data freshness — and each approve/reject verdict is persisted before returning.

🤖

Multi-Model AI Routing

Claude Sonnet for deep reasoning, Claude Haiku and Gemini 2.5 Flash for cheap batch sentiment, and Gemini 2.5 Pro for contrarian second opinions via /api/gemini/second-opinion — cost-aware routing by task complexity.

📈

Quant Engine Stack

Market regime detection (ADX/Bollinger/RSI) with a live FRED macro layer, Monte Carlo stress tests (1000 GBM paths), Kelly Criterion sizing, FFT cycle detection, and EWMA vs GARCH(1,1) volatility comparison.

⚙️

Paper Execution + Autopilot

PAPER_MODE-by-default execution layer with SHA idempotency and a Telegram-alerting APScheduler autopilot running scan/execute/rebalance/EOD jobs on an Eastern-Time cron — accumulating win-rate proof with no real money at risk.

🗄️

Auditable Signal Pipeline

The full signal → gate → execute chain is logged across SQLite tables (trade_intents, risk_decisions, orders) so every simulated fill traces back to the signal and gate verdict that produced it.

🔎

Scanner Pipeline

Cheap ETF sector pre-filter, then consolidation-zone detection (10+ candle tight ranges, min 2.0× R/R), then full engine analysis only on hot symbols — across eight timeframe modes from 5MIN to forex-daily.

⏱️

Deterministic Daily Chain

launchd fires run_daily_analysis.sh at 10:30 ET weekdays: live snapshot → all engines → one bounded Claude call → paper/risk-gate audit with Telegram signal alerts → self-asserting HTML report at /report — the full analysis in ~4–6 minutes, no agent in the loop.

💡

Advanced Portfolio Analytics

IRS wash-sale tax-loss harvesting, per-holding alpha vs SPY and 30+ sector ETFs (A–F grade), rolling 90-day BTC/ETH correlation, plain-English consensus explainability, and 3-tier DeFi yield comparison.

🔐

Auth, Billing & Data Rights

Per-user login wall (GESH_AUTH_ENABLED) with isolated accounts, Lemon Squeezy subscriptions with usage quotas, public legal pages (/privacy · /terms · /disclaimer, DRAFT pending counsel), and self-serve data rights — in-app export and account deletion, with a GESH_SIGNUPS_PAUSED kill-switch.

It sits between one operator and a fan of external market, AI, and intelligence APIs — ingestion feeds the quant engines and intelligence agents, which feed the consensus and AI-routing layer, which hands verdicts to the trading execution subpackage, all backed by dual SQLite stores.

How It Works

A chosen verdict becomes a typed TradeIntent, runs through the eight ordered risk gates (each persisted), and on approval writes a SIMULATED paper order with an idempotency key — optionally firing a Telegram alert. The data flow below traces the primary POST /api/deep-analysis path and the signal → gate → execute pipeline.

🔁

End-to-end data flow

  • Robinhood holdings, equity and quotes are pulled via robin_stocks and written to gesh_live_cache.json as an atomic snapshot.
  • yfinance history/fundamentals and FRED macro (Fed funds, yield curve, CPI) feed the quant engines (regime, Monte Carlo, Kelly, FFT, volatility).
  • Intelligence agents (news, SEC, fundamentals) write per-symbol sentiment and filing scores into gesh.db.
  • The 11-node consensus engine combines quant signals plus cached sentiment into a per-symbol verdict and confidence.
  • Consensus output and regime context are routed to Claude (forced tool-use JSON) for deep per-holding analysis.
  • Analysis runs, equity snapshots and signals are persisted to gesh_financial.db.
  • A chosen verdict becomes a typed TradeIntent through the 8-gate risk gate, each verdict persisted to risk_decisions.
  • On approval the execution layer writes a SIMULATED paper order (idempotency key) to the orders table and optionally fires a Telegram alert.

⏱ Automation

The Daily Chain

Every weekday at 10:30 ET, launchd fires run_daily_analysis.sh — a lock-protected, self-asserting orchestrator that replaced a 40-minute agent-driven workflow with ~4–6 deterministic minutes. It merge-writes engine_results.json with freshness stamps, saves to the analysis DB, audits its own action plan through the 8 risk gates (paper mode), pushes a timestamped Telegram signal alert, and publishes the HTML report.

Quickstart

Clone, create a virtualenv, install dependencies, add your keys, and launch the dashboard on port 9000.

Install
# 1 — clone & enter
git clone https://github.com/gesh75/gesh-project.git
cd gesh-project

# 2 — virtualenv
python -m venv venv
source venv/bin/activate

# 3 — dependencies
pip install -r requirements.txt

# 4 — create .env with ANTHROPIC_API_KEY
#     and your trading defaults
Run
# web dashboard on port 9000
python server.py

# with the login wall (paid-beta default)
GESH_AUTH_ENABLED=true python server.py
# pause new signups: GESH_SIGNUPS_PAUSED=true

# CLI quick analysis
python main.py

# autopilot, paper mode
PAPER_MODE=true python -m trading.autopilot

# single autopilot job
python -m trading.autopilot \
  --job pre_market_scan

# daily chain manually (launchd runs it 10:30 ET)
bash run_daily_analysis.sh
#   report: http://localhost:9000/report
